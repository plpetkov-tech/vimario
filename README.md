# Vimario

A browser game for practicing Vim motions through platforming and text puzzles.

Play: https://plpetkov-tech.github.io/vimario/

## Local preview

Run `npm start`, then open http://localhost:8765/.

## Checks

Run `npm test` for the course playthroughs, Fuse checks, and room-framing checks.

## Deployment

GitHub Pages serves the root of the `main` branch. Push changes to `main` to publish an update. No build step is required; `.nojekyll` keeps the site as plain static files.

Game progress is saved in each player's browser.
